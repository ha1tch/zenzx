# ZENZX

A ZX Spectrum emulator: 48K, 128K, +2, +2A, +3, the Spanish
variants of each, and the Timex Sinclair 2068.

Hover the mouse near the top edge of the window and hold still
for a moment to reveal the menu bar. It's the primary way to
control the emulator; every action it offers also has a keyboard
shortcut below, for anyone who prefers not to wait for it to
appear.


## Top menu bar

  Machine        reset, pause/resume, pick a model (grouped by
                 manufacturer -- Sinclair, Amstrad, Investronica,
                 Timex)
  Custom ROM     load a ROM file live from -custom-roms-dir
  Tape           play/stop, rewind, accurate/fast mode, tape info
                 (a window with its file, state and blocks)
  Floppy Disk    open a .dsk image, save, insert blank, eject,
                 save as, disk info (+3 and Spanish +3 only)
  Snapshot       quick save/load, save timestamped, snapshot
                 info, run diagnostics
  View           FPS and border are checkboxes now, not one-shot
                 actions; status display
  Theme          Dark, Light, or Spectrum (the real 128K/+2/
                 +3 boot menu's own palette, rainbow and all)
  Font           six bundled bitmap faces, plus zoom X1/X2/X3

The rainbow (Spectrum theme) or logo (Dark/Light themes) on
the right of the bar has its own menu: click it for this help
screen, an About box, pinning the bar so it stops auto-hiding,
and a link to the project's own page.


## Keyboard shortcuts

  F1             Reset
  F2             Pause / Resume
  F3             Show status
  PgUp / PgDn    Scale window up / down
  Alt+F          FPS counter on/off
  Alt+B          Border on/off (animates the window size)
  Alt+M          Machines: the dock at the bottom edge, also opened by
                 resting the mouse there. Arrows and Enter (or a click)
                 bring a machine to the front, New adds one, Delete
                 closes the chosen one, F2 renames it, and a picture
                 dragged onto a tile puts the machine there.

  F9             Quick save
  F10            Quick load
  F11            Save snapshot
  F12            Snapshot info (Shift+F12: run diagnostics)


## Tape (when a tape is loaded)

  Alt+P          Play / Stop
  Alt+R          Rewind
  Alt+T          Accurate / Fast mode
  Alt+I          Tape info


## Disk (+3 and Spanish +3 only)

  F4             Save disk
  F5             Insert blank disk
  F6             Eject disk
  F7             Disk info
  F8             Save disk as (timestamped)


## Command line

  -model=NAME        48k, 128k, plus2, plus2a, plus3,
                      spanish48k, spanish128k, spanishplus2,
                      spanishplus3, ts2068, next
  -bootrom=PATH       Next: the 8K boot ROM (nextboot.rom)
  -divmmc-rom=PATH    Next: the DivMMC ROM (enNxtmmc.rom)
  -sdcard=PATH        Next: the SD card image; see the manual,
                      "ZX Spectrum Next", for how to make one
  -sdcard-readonly    write-protect the card
  -next-files=DIR     Next: folder with nextboot.rom, enNxtmmc.rom and next-card.img
                      (default: NEXT_FILES, ./next, ./thirdparty, then the per-user
                      folder; next/README.md).
                      Without the files the GUI offers to download them, once
  -next-classic       Next: run with the +3 ROMs, not NextZXOS
  -nextreg-log=LIST   Next: log writes to these NextREG registers (hex, comma
                      separated, or all) to the terminal
  -next-examples      Next: put ZenZX's example programs on its own card for
                      the second slot (zenzx-card.img beside the boot files),
                      and exit (examples/next/README.md)
  -next-add=FILES     Next: put these files (comma separated) on that card,
                      and exit
  -next-new-card=PATH Next: make a new, empty SD card image (FAT32, 280 MB),
                      and exit
  -next-issue=N       Next: the board issue, 5 (4 MB, the default), 4 or 2
                      (2 MB): how much memory DMA+ reaches
  -sdcard2=PATH       Next: the card image for the second SD slot (default:
                      zenzx-card.img when it is there; none for an empty slot)
  -next-setup         headless: download the Next boot files, build and verify
                      the card, and exit (-next-distribution=URL, -next-bootrom-url=URL)
  -next-dump          (headless) print the Next's registers,
                      mapping and palettes at the end of the run
  -theme=NAME         Dark, Light, or Spectrum
  -settings=PATH      settings.json path (theme/font/zoom/scale/
                      fixed-bar persistence; default settings.json)
  -disk=FILE          mount a .dsk at startup (+3 models)
  -snapshot=FILE      load a snapshot at startup
  -format=FORMAT      snapshot format: sna, z80, szx (load only), zxs, auto
  -audiobackend=NAME  raylib or oto

Examples:

  ./zenzx -model=48k
  ./zenzx -model=128k
  ./zenzx -model=plus3 -disk=game.dsk
  ./zenzx -snapshot=saved.sna -format=sna
