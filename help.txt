# ZENZX

A ZX Spectrum emulator: 48K, 128K, +2, +2A, +3, the Spanish
variants of each, and the Timex Sinclair 2068.

Hover the mouse near the top edge of the window and hold still
for a moment to reveal the menu bar. It's the primary way to
control the emulator; every action it offers also has a keyboard
shortcut below, for anyone who prefers not to wait for it to
appear.


## Top menu bar

  File           open any file the program loads, preferences
                 (every saved setting in one window), quit
  Machine        reset, pause/resume, pick a model (grouped by
                 manufacturer -- Sinclair, Amstrad, Investronica,
                 Timex)
  Custom ROM     load a ROM file live from -custom-roms-dir
                 (its folders are submenus);
                 Download more ROMs opens the pages where
                 ROMs are published (custom-roms/rom-archives.json;
                 Rodolfo Guerra's mods and the Speccy4ever
                 archive when it is not there)
  Tape           play, stop and rewind buttons, accurate/fast
                 mode as radio buttons,
                 tape info (a window with its file, state and blocks)
  Storage        the same two sections on every model: a +3's
                 floppy drive (open a .dsk image, save, insert
                 blank, eject, save as, disk info) and a Next's
                 SD cards (slot 2). Greyed, with the reason,
                 where the machine has none; results show as
                 a toast
  Snapshot       quick save/load, save timestamped, load
                 timestamped (the ten newest, More... for the rest),
                 save as (a format: .zxs, .sna or .z80, then a name),
                 load snapshot, recent snapshots (the named ones),
                 save and load multisnapshot (.zms: every machine
                 and the layout; loading replaces the machines,
                 after you type YES),
                 manage snapshots (load, duplicate, rename, delete),
                 load binary (a file into memory, peek and poke, and
                 a hex editor, in the CPU's memory or a RAM page),
                 snapshot info, run diagnostics. All go in snapshots/
  View           FPS and border checkboxes (the border is greyed
                 where the picture decides it: tiled layouts, full-
                 frame Layer 2 modes), status, zoom X1-X3, and the
                 layouts for several machines
  Theme          Dark, Light, or Spectrum (the real 128K/+2/
                 +3 boot menu's own palette, rainbow and all)
  Font           six bundled bitmap faces, plus zoom X1/X2/X3

The rainbow (Spectrum theme) or logo (Dark/Light themes) on
the right of the bar has its own menu, the Help menu, in
sections: Help (this screen, the manual as a PDF, an About box,
the Acknowledgements and a link to the project's own page) and Tools (Developer >
Debugger). The bar's settings are in File > Preferences.


## Keyboard shortcuts

  F1             Reset
  F2             Pause / Resume
  F3             Diagnostics (a window)
  PgUp / PgDn    Scale window up / down
  Alt+F          FPS counter on/off
  Alt+B          Border on/off (animates the window size)
  Alt+Enter      Full screen on/off (View menu: Full Screen; also F11)
  Alt+1 .. Alt+9 With -multi: give the keyboard to that machine
  Alt+M          Machines: the dock at the bottom edge, also opened by
                 resting the mouse there. Arrows and Enter (or a click)
                 bring a machine to the front, New adds one, Delete
                 closes the chosen one, F2 renames it, and a picture
                 dragged onto a tile puts the machine there.

  F9             Quick save
  F10            Quick load
  F11            Full screen on/off (the same as Alt+Enter)
  Shift+F11      Save snapshot, named by the date and time
  F12            Snapshot info (Shift+F12: run diagnostics)


## Tape (when a tape is loaded)

  Alt+P          Play / Stop
  Alt+R          Rewind
  Alt+T          Accurate / Fast mode
  Alt+I          Tape info


## Disk (+3 and Spanish +3 only)

  F4             Save disk
  F5             Insert blank disk
  F6             Eject disk
  F7             Disk info
  F8             Save disk as (timestamped)


## Command line

  -model=NAME        48k, 128k, plus2, plus2a, plus3,
                      spanish48k, spanish128k, spanishplus2,
                      spanishplus3, ts2068, next
  -bootrom=PATH       Next: the 8K boot ROM (nextboot.rom)
  -divmmc-rom=PATH    Next: the DivMMC ROM (enNxtmmc.rom)
  -sdcard=PATH        Next: the SD card image; see the manual,
                      "ZX Spectrum Next", for how to make one
  -sdcard-readonly    write-protect the card
  -next-files=DIR     Next: folder with nextboot.rom, enNxtmmc.rom and next-card.img
                      (default: NEXT_FILES, ./next, ./thirdparty, then the per-user
                      folder; next/README.md).
                      Without the files the GUI offers to download them, once
  -next-classic       Next: run with the +3 ROMs, not NextZXOS
  -nextreg-log=LIST   Next: log writes to these NextREG registers (hex, comma
                      separated, or all) to the terminal
  -next-examples      Next: put ZenZX's example programs on its own card for
                      the second slot (zenzx-card.img beside the boot files),
                      and exit (examples/next/README.md)
  -next-add=FILES     Next: put these files (comma separated) on that card,
                      and exit
  -next-new-card=PATH Next: make a new, empty SD card image (FAT32, 280 MB),
                      and exit
  -next-issue=N       Next: the board issue, 5 (4 MB, the default), 4 or 2
                      (2 MB): how much memory DMA+ reaches
  -sdcard2=PATH       Next: the card image for the second SD slot (default:
                      zenzx-card.img when it is there; none for an empty slot)
  -next-firmware=ACTION
                      Next: setup downloads the boot files, builds and verifies
                      the card; check says where they are and whether a Next
                      can start from them; cleanup deletes what a download that
                      did not finish left. Then exit (-next-distribution=URL,
                      -next-bootrom-url=URL change the addresses)
  -next-setup         the older spelling of -next-firmware setup
  -next-dump          (headless) print the Next's registers,
                      mapping and palettes at the end of the run
  -theme=NAME         Dark, Light, or Spectrum
  -settings=PATH      settings.json path (theme/font/zoom/scale/
                      fixed-bar persistence; default settings.json)
  -disk=FILE          mount a .dsk at startup (+3 models)
  -snapshot=FILE      load a snapshot at startup (starts the model it is of, unless -model is given;
                      a Next's snapshot needs the cards it was made over, and says which if it has not got them)
  -format=FORMAT      snapshot format: sna, z80, szx (load only), zxs, rzx (a recording to play), auto
  -audiobackend=NAME  raylib or oto

Examples:

  ./zenzx -model=48k
  ./zenzx -model=128k
  ./zenzx -model=plus3 -disk=game.dsk
  ./zenzx -snapshot=saved.sna -format=sna


## Command line, more

  -scale=N            the window's first zoom, 1 to 5
  -noborder           start without the border
  -noaudio            no sound
  -version            print the version and exit
  -tape=FILE          load a .tap or .tzx
  -tapemode=MODE      fast (the default), accurate or turbo
  -scr=FILE           show a .scr screen dump
  -script=FILE        drive the emulator with a .zen action script
  -rom0=FILE .. -rom3=FILE
                      replace that one ROM bank of the model's set
  -custom-roms-menu   pick a ROM and the bank for it before starting
  -nofdc              no floppy controller on a +3
  -debugfdc           the floppy controller's trace, on the terminal
  -joystick=MODE      auto, none, kempston, kempston2, kempston-both, sinclair
                      (sinclair1), sinclair2, sinclair-both or cursor
  -mouse=MODE         auto, none, kempston or amx
  -escape=MODE        what the Escape key does: off (the default), close,
                      query or on
  -language-switch=P  spanish or portuguese: the Microdigital language switch
  -snapshots-dir=DIR  the folder of the snapshots (default snapshots)

  Memory, in a running machine (Snapshot > Load Binary... does the same):

  -bin=FILE           put a raw binary in memory
  -binaddr=ADDR       where, hex 0x.. or decimal (default 0x8000)
  -binpage=N          in a RAM page instead of the memory the CPU sees: a bank
                      0-7 on a 128K, +2, +2A or +3, an 8K page 0-223 on a Next;
                      -binaddr is then the address in the page
  -binstart=ADDR      the program counter after it (default: the address; with
                      -binpage none; -1 leaves it alone)

  Several machines:

  -multi=SPEC         start several: 3, 12,128k, 4:48k,48k,128k,next
  -layout=NAME        how the window tiles them: single, columns, rows, grid,
                      main-left or main-right
  -focus-follow       the keyboard follows the player beacon at 0xBFFE
  -autorun=FILE       type in and run a BASIC program (a file of numbered lines)
  -listen=PORT        a TCP link to each machine (ports 16384 and 16385 in it);
                      -listen-host=ADDR is the address it listens on

  The Next and the rest:

  -next-bootable=CARD make that card image one a Next can boot from, and exit
  -next-boot-cache=M  auto, off or refresh: start from the state of a Next that
                      has booted instead of booting
  -divmmc-debug       the DivMMC and SD card trace, on stderr
  -non-standard=on    allows -ns-graphics=MODE and -ns-storage=NAME, which are
                      not a real machine (the manual, "Non-standard features")
